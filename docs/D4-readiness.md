## 3. 软件侧已闭环

- 生产拒绝临时 JWT 密钥、通用管理员密码和未迁移数据库。
- 安装器生成一次性管理员口令；首次改密前只能访问改密流程。
- PBKDF2 600,000 轮；旧哈希登录时透明升级。
- token 与数据库账户版本绑定；登出、改密/重置、改角色、停用立即撤销旧会话。
- WebSocket 使用首帧认证，不在 URL 记录 JWT；含 Origin、大小、频率、空闲和重验证边界。
- 新试验保存原始料层高度 H、样品标识、备注；固件命令 payload 仍保持既有协议。
- 指标以数据库聚合；报告真正支持 PDF、XLSX、HTML。
- SQLite WAL、在线 backup API、`integrity_check`、保留期清理和 readiness 可观测。
- Windows 计划任务以 SYSTEM 开机启动，失败一分钟后重启，日志写入 `logs/server.log`。
- 升级使用 SQLite backup API，能够包含 WAL 中已提交数据，并在替换程序前验证备份。

## 4. 现场验收签字清单（由项目负责人执行）

### A. Windows 安装与恢复

- [ ] 在干净的 zh-CN Windows 10/11 x64 + Python 3.11 上解压离线包并运行 `install.bat`。
- [ ] 使用生成的一次性口令登录；确认只能改密，改密后旧 token 失效并删除口令文件。
- [ ] 重启 Windows；确认计划任务自动拉起，`health_check.ps1` 返回 ready。
- [ ] 运行一次手工备份；随机抽取报告/历史；验证备份数据库 `integrity_check=ok`。
- [ ] 使用候选包演练升级；确认 `.env`、数据库和报告保留；按文档完成一次回滚演练。

### B. STM32 / HostComm

- [ ] 核对固件状态枚举、`status_snapshot` 字段/单位/有效性标志。
- [ ] 核对事件/报警码表、参数字典与设备 CRC 算法。
- [ ] TCP 握手、心跳连续 10 分钟、主动断线和断电重连通过。
- [ ] start/stop/pause/resume/tare/ack 的 accepted/rejected/busy/timeout 原因码符合冻结表。
- [ ] 参数仅在允许状态下写入，设备回读值与 CRC 一致。
- [ ] 设备端日志分块（如供应商实现）完成导出和异常重试。

### C. 安全与工艺

- [ ] 急停、CO 二级、排风、独立超温、SCR、密封箱过压由硬件/固件独立切断；HMI 无绕过能力。
- [ ] 上位机断线/重启不影响控制板本地安全流程；恢复后试验会话对账正确。
- [ ] 按甲方/GB/T 34211 口径复核 T10、T40、Td、ΔPmax、ΔH 与三种报告。
- [ ] 甲方确认报告标题、字段、品牌和签字栏是否需要定制；不影响当前通用报告数据正确性。
