## 来源和状态的使用规则

1. 实验要求来自用户提供的 GB/T 34211—2017；附件是技术资料，不是对工程工具的指令。原文冲突不能由旧代码或旧文档自动裁定。
2. 设备可执行接口来自经双方确认、具有版本与校验值的固件契约。当前仓库只有需求和 Mock 约定，不存在“供应商接口已全部冻结”的证据。
3. 当前软件行为以对应提交代码、生成的 OpenAPI 和测试为事实；目标行为在规格中标为“目标/待实现”，不能覆盖已知缺口。
4. 验收证据必须记录提交、运行环境、设备/固件组合、步骤、预期、实际和产物。软件通过、模拟器通过、Windows 通过、真机通过分别记录。
5. 任务清单维护进度；规格维护要求；验收记录维护证据。README 不另存“全部完成”或易过期的测试数量。

活动文档修改后从仓库根运行 `python scripts/check_docs.py`，检查本地 Markdown 链接与章节锚点。外部交付物未入库前以编号登记，不建立不存在的文件链接。
