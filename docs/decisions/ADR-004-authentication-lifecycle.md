# ADR-004：数据库校验会话，独立管理初始口令生命周期

## 状态与日期

已接受，2026-09-05；替代 [ADR-001](ADR-001-forced-password-change.md) 的互相矛盾论证。本 ADR 描述 dev@855c84d 已存在的机制，不宣称新增安全功能已经验收。

## 背景与决策

原 ADR 同时写入随机初始口令，又以离线分发困难为由拒绝随机口令；还声称不查询数据库，与现有认证代码不符。

生产安装生成一次性管理员口令，以受 ACL 保护的文件分发。首次登录仅允许本人查询、登出及修改本人密码，改密成功后清除强制改密状态、写审计并重新登录。默认弱口令仅限显式 Mock 开发模式。

REST 的受保护请求和 WebSocket 首帧认证均对照数据库校验账户有效性、角色和 token_version；改密、停用或改角色撤销旧会话。WebSocket 不在 URL 中传 JWT，收到客户端 ping 时再次校验会话。前端将令牌放在 sessionStorage，登出时清理。

## 后果与边界

接受本地数据库查询成本，以便立即执行权限撤销。首次口令交付与数据库迁移是不同流程，不能给已有用户自动重建弱口令。JWT 到期和服务器校验不替代局域网 HTTPS，也不替代后台控制权限。具体代码来源为 `backend/app/api/deps.py`、`backend/app/api/websocket.py`、`backend/app/core/security.py`。
