# ADR-010：安装版通信与实验恢复验收

日期：2026-09-07。状态：已接受，实施和验证见任务清单及对应证据。

## 问题

rc.4 的安装、Python TLS 联调和页面验证各有记录，尚未通过同一真实安装版证明从配方到报告的连续流程。租约时序存在竞态，陌生运行仅保留原始数据，缺少受控归档入口。

## 决策

- `hello_ack.control_ready` 是握手时的提示；持续控制依据当前角色、配置批准、状态新鲜度与租约。心跳更新租约证据，不更新实验阶段。
- 租约绑定 boot/session/id/本地代次。期限保守映射为请求开始单调时间加响应剩余租期；旧回执不得恢复或清除新代次。心跳写锁、发送、ACK 共用3秒；按发送起点2秒调度，单个在途。重连实际不超过30秒，稳定30秒且有效心跳后重置退避。板端8秒租约保持不变。
- 未知运行先持久发现，管理员/维护员以理由、幂等键和审查版本绑定并回放。归档不恢复设备控制，不替代源测定/安全边界。真实开始时间允许未知，与发现时间分别存储；数据迁移不推断历史资料。
- `SmdBench` 是独立 Windows x64 onedir 工具，内含 Python、Playwright/Chromium和无执行器模拟器。私有 JSONL 管道只允许固定故障/场景动作；设备网络限loopback。生产安装器和API不增加测试后门。
- 工具在全新归属明确的测试安装中执行安装、配对、TLS、页面、报告及清理。CI保留既有安装冒烟，再在清理后的环境运行工具独立安装流程，避免交接内部安装所有权。增加一次安装成本，换取两个入口相同的拒绝接管规则。
- 合成场景只注入明确阶段事件，不加速租约/心跳时钟。指标预期独立核算；模拟报告保留 `not_certified`。证据白名单排除凭据、配置、数据库和会话。
- Windows服务收到停止信号后，HTTP/WebSocket请求排空最多15秒，随后取消未结束请求并沿用Uvicorn生命周期清理；15秒不是整个进程退出期限。SCM仍要求实际Stopped，现有60秒停止检查及进程互斥锁不变。尚未提交的回执允许回滚为持久的未知结果，重启后只能查询原操作，不将取消当成执行成功或自动重发依据。清理遇到StopPending只等待终态，未确认Stopped不能删除服务或数据。

## 接口与兼容

新增 `/api/run-recoveries` 列表/详情及绑定、回放接口；写操作有审计并发控制。恢复报告回放未完成时拒绝生成。HostComm保持 `2.0 / 2.0-design.1`，文档修订为 `2.0-doc.3`；应用沿RC序列发布，旧标签不移动。

## 验收边界

Windows CI证明安装版服务、TLS、Chromium页面和实际导出。Win10/11 WebView2、窗口关闭后持续采集、中文路径与缩放仍单列人工验收；固件、电气联锁、国标工艺时长、24小时与真机验收独立记录。不能将工具通过解释为现场正式发布资格。
