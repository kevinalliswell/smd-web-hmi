# STM32H750VBT6 工控板资料

资料整理日期：2026-09-06。适用对象：用户为本项目提供的 **STM32H750VBT6 工控板**。板卡厂商、商品编号、PCB 修订和芯片实物修订尚未提供；不能据本文认定所有 H750VBT6 板卡具有相同接线。

本页保存板卡资源、接口位置与引脚表，供采购核对、BSP 开发和现场维护使用。来源是用户提供的三张图片；其中的资源和性能标注属于资料声明，未经过本项目实板验收。器件数据手册只用于解释容量、接口和限制，不能证明本板的实际布线。通讯和存储的工程要求见 [STM32H750 工程 profile](../hostcomm/v2/stm32h750-profile.md)，开发任务见 [FW-01—10](../../tasks/todo.md#hostcomm-v20-与新固件)。

## 复用、冲突与图中文字疑点

| 编号 | 图片依据 | 处理要求 |
|---|---|---|
| HW-01 | PC6/PC7 同时用于 SP2/USART6 和 ENCOD/TIM3；B2 说明 PU6_ENCOD 跳至 SP485 或 PWMIN | 明确互斥，保存实际跳帽位置；不能承诺 4 路 RS485 与 2 路编码器全部同时可用 |
| HW-02 | PD7 同时出现在 GLIN3 与运行灯 | 可能是共享电路或印刷错误；等待原理图/实测，禁止当作两个独立 GPIO 配置 |
| HW-03 | SPI3 的 PB4 同 GLIN3，PB5 同第二路 CAN，PA15/PB3 同第二路编码器 | 建立并发资源矩阵；逐项选择功能、核对 AF 和板上连接 |
| HW-04 | ADC1/ADC2 上半表将六根 MCU 信号与八个 CH 放在一起，下半表明确为 SPI4/ADS8688 | 按外置 ADC 驱动建模，不把六根控制线分配成模拟通道 |
| HW-05 | B3 写“外频 480M” | 原样保留为疑点；不能按 480 MHz 配置外部晶振，也不能证明目标芯片可在该频率运行 |
| HW-06 | B1 写 ADC 500KHZ，B2 写速度 500K；另有“或 8 路 NTC 温度” | 分开记录器件转换率、各通道有效采样率与遥测频率；不据此添加 8 个独立已验证 NTC 接口 |
| HW-07 | GLOUT2 的共用备注仍写“另一端接 GLOUT1 上的任意接头” | 疑似复制文案；电源公共端、驱动极性和负载回路按原理图核对 |
| HW-08 | W25Q128 仅列 SPI2 四个引脚；图片未出现 SD 卡资源 | 不推定 Quad-SPI 接线、映射执行或存在 SD 卡；完整型号和实装总线待验 |

B3 另声明正常工作温度 −40～75 ℃、待机功耗约 0.6 W、RS485/CAN 速率 1M。这些没有测试环境、负载或误码条件，保留为采购核对项，不写成项目验收指标。

## 对固件与通讯实现的影响

1. **以网络作为上位机入口。** 后台经 Ethernet 与板端通讯；RS485、CAN、模拟量和开关量由板端驱动管理。板卡资料不增加绕过状态机的直接 I/O 命令。网络认证、租约、停止和日志语义仍遵守 [HostComm 2.0](../hostcomm/v2/README.md)。
2. **先核对启动与存储可行性。** W25Q128 和 24C02 已有资料依据，不能继续写成“外部存储完全未知”；但容量不等于可靠事务能力。为程序、配方、操作高水位和采样日志分别规划空间、擦写与恢复。外部 Flash 若确为普通 SPI2 接线，不能预设 Quad-SPI 映射执行；最终启动/装载方案需依据 map、RAM 和原理图单独验证。
3. **采样与上传分层。** ADS8688 的转换能力不等于仪表刷新速度、8 路同时采样能力或上位机遥测频率。冻结每个传感器的实际采样周期、同步关系、滤波、延迟和数据新鲜度，再确定源日志与网络预算。
4. **为仪表建立受控点表。** 每项记录逻辑量、端子、MCU 资源、仪表型号/地址、量程/单位、气体参考状态、标定、读写周期及故障判定。RS485 上存在多个站点时还需计算轮询和超时预算；不能凭 4 路端口就指定所有 MFC 通道。
5. **复用先解决，再接物理输出。** 建立实际启用资源矩阵和跳帽照片；验证复位/启动/看门狗/掉电时的输出状态。板上隔离和驱动功能不能代替整机急停、CO、排风和超温联锁的电气设计。
