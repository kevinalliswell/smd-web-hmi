# HostComm 文档修订与兼容版本

当前文档修订：`2.0-doc.2`，2026-09-07。交接入口为[固件开发交接](firmware-handoff.md)，实现核对为[兼容表](compatibility.md)。

## 四种版本分别使用

| 对象 | 当前值 | 使用位置 |
|---|---|---|
| 文档修订 | `2.0-doc.2` | 交接、修订记录和验收材料；不进入线上报文 |
| 协议版本 | `2.0` | 每个消息包络的 `protocol_version` |
| 设计/机器契约修订 | `2.0-design.1` | hello/hello_ack 的 `design_revision`；现有模型精确匹配 |
| 候选软件版本 | `0.3.0-rc.4` | SmdHmi安装包、页面、应用与发布清单 |

本轮只修订文档，补齐已有实现的说明并公开未对齐项；不修改消息模型、Schema、固定向量、应用版本或既有发布标签。把 `2.0-doc.2` 写入 hello 会被当前软件拒绝。
