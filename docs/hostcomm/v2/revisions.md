# HostComm 文档修订与兼容版本

当前文档修订：`2.0-doc.4`，2026-09-20。实操主入口为[技术交底](technical-briefing.md)，职责与变更规则见[固件开发交接](firmware-handoff.md)，实现核对见[兼容表](compatibility.md)。

## 版本分别使用

| 对象 | 当前值 | 使用位置 |
|---|---|---|
| 文档修订 | `2.0-doc.4` | 交接、修订记录和验收材料；不进入线上报文 |
| 协议版本 | `2.0` | 每个消息包络的 `protocol_version` |
| 设计/机器契约修订 | `2.0-design.1` | hello/hello_ack 的 `design_revision`；现有模型精确匹配 |
| 上位机软件版本 | `0.3.0` | 已发布的 SmdHmi 安装包、页面、应用与发布清单 |
| 固件版本 | 待交付 | 开发中、尚未交付验收；固件负责人登记版本、源码及二进制 SHA |

本轮是说明性修订，协议字段、Schema、向量和握手版本保持不变，不重新发布应用或移动既有标签。`0.3.0` 的软件发行证据见[覆盖安装与正式发布验证](../../verification/2026-09-13-overwrite-install.md)，不构成真实板卡或实体安全验收。

## 当前交底基线

- 已发布上位机：`v0.3.0` → `404ecb50edf23864ed482e68cc4a1933deb3383f`。
- 本轮文档工作起点：`main@bf8a1953a721ea2087b24ca86055733d00317216`。该提交的 `backend/app/hostcomm` 和 `contracts/hostcomm/v2` 与发布标签一致；交底以发布版本为准。
- 文档与离线源码快照：采用本次 PR 最终提交，完整 SHA、文件清单及摘要由离线包元数据登记，避免把工作起点当最终交付提交。
- 现场状态：用户于 2026-09-20 确认 `0.3.0` 安装成功；只登记安装结果，不据此补记配对、数据保留或真实通信通过。
- 固件开发中、尚未交付验收。硬件资料为 STM32H750VBT6 板卡；板卡修订、原理图与工程 profile 仍待核实。

每次交底和联调固定完整源码快照，不只发送“main最新版”。保存双方版本、Schema/向量 SHA-256、离线 ZIP 摘要及固件构建材料，确认双方拿到同一份文件；现场凭据另行受控交接。
