# 无设备测试机备份与空库重装：来源和验证边界

2026-09-06，用户在旧HostComm 1.0软件中准备升级，现场返回“升级要求设备在线、状态新鲜且明确空闲”。此前日志已确认覆盖安装缺少维护准备文件，见[安装错误排查记录](2026-09-06-windows-installer-errors.md)。这次反馈补充证明：该测试机当前的离线1.0入口无法完成正常升级准备。

用户选择完整备份并保留旧资料，再用新版本建立空数据库。适用对象为无实体设备连接的专用测试机；新增工具不是现场设备的通用维护豁免，也不改变1.0门禁或配对设备的安全条件。

## 本次交付

- [操作说明](../../deploy/windows/TEST-REINSTALL.md)与[PowerShell脚本](../../deploy/windows/reset-test-installation.ps1)：默认只读预览，执行须同时指定`-Apply -ConfirmNoDeviceAttached`。
- 支持范围限定实际Program Files中的受控安装目录、默认ProgramData数据目录及`db\smd.db`；非默认路径拒绝。
- 执行先保存并校验程序、数据、注册信息、任务和服务元信息，再清理旧安装并保留原始目录；备份包含秘密，须保持受限访问。
- 清理成功后使用已经发布的`0.3.0-rc.4`安装器首次安装，不创建新tag、不修改既有发布资产、不自动导回旧配置或数据库。
