### 原版问题与未验范围

- 桌面原版 `test_frozen_backend_migrates_and_loads_http_websocket_runtime` 成功构建冻结 probe 后，捕获子进程输出发生 GBK/UTF-8 解码异常，继而拼接 `None` 失败。该失败没有证明运行时正常，也不能归因 Tauri；P1 先修复输出捕获再复验。Windows symlink/管理员 ACL 等跳过项按既有条件执行，没有通过提权掩盖。
- 继续执行剩余桌面测试的命令为上述命令去除 `--maxfail=1` 并增加 `-k 'not frozen_backend_migrates_and_loads_http_websocket_runtime'`。`test_cli_reports_failure_without_traceback_when_compiler_cannot_start` 同样因子进程编码不一致失败；`test_recovery_reads_storage_minimum_from_verified_backup_when_config_is_missing` 因 C 盘剩余 1,771,855,872 字节小于其配置的 2 GiB 数据库安全余量失败。没有修改余量或生产检查来使测试通过；后续用隔离且空间足够的测试目录复验。
- audit 涉及 Vue、Vite、Vitest/mocker、brace-expansion、follow-redirects、source-map-js、postcss-selector-parser。当前锁保持原版，P1 以独立前置任务处理；P0 不声称 CI 全绿。
- 未执行旧版完整安装、覆盖升级、打印、真实桌面 WebView2、LAN/真实设备或 24h 长稳。源码 API 运行、冻结 probe 构建和完整安装验收分别判断。

### 隔离运行与测量口径

脚本 [baseline.py](../../tools/modernization/baseline.py) 创建临时 SQLite、合成的非完整试验及随机测试凭据，启动独立 loopback HostComm 1.0 mock 和 FastAPI，通过公开 API 登录、认证 WS ping、等待设备 online，再生成并下载 HTML/PDF/XLSX 核验文件签名。每次运行显式配置 1.0/Mock，不访问现场配置、密钥、数据库或设备，不发送物理控制请求；不把合成数据当有效国标试验。结束清理两个子进程及临时库。夹具以脚本确定的 3600 个样本与显式配置重建，随机密码不影响业务数据。

最初成功运行摘要：启动至 ready **11.706 秒**，服务工作集 **145,686,528 → 152,174,592 字节**；HTML **0.721 秒 / 4,053 字节**，PDF **0.680 秒 / 6,155 字节**，XLSX **0.792 秒 / 8,371 字节**；HostComm online、认证 WS ping 通过。最终脚本复验启动 **4.937 秒**、服务工作集 **145,670,144 → 152,199,168 字节**，三个报告分别 **0.343 / 0.372 / 0.399 秒**，产物字节数一致；见[机器记录](2026-10-22-tauri-p0-baseline.json)。两轮不同负载，不能据其差异声称性能提升。

工作集读取实际 Python 服务进程，排除了 Windows venv redirector；只计算服务，不含 UI、Mock、安装运行时或整机。单次冷启动与报告采样同其他测试共用本机资源，不能当性能 SLA；P1 与后续需在同等负载下重复比较。报告耗时包含请求、轮询及下载，且合成不完整试验会减少分析内容，不替代大报告验收。

原始日志/JSON 在忽略的 `artifacts/modernization/`，数据库、凭据、报告正文不提交；入库只保留脱敏指标摘要。早期 redirector 内存测量无效，未采用。
