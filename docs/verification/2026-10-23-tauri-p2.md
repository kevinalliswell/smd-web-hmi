# P2 持久任务与渲染隔离验证记录

基线：`codex/tauri-p1@8f8a892`；分支 `codex/tauri-p2`，草稿 PR 基线为 `codex/tauri-p1`。用户明确要求继续 P2；P1 的人工登录、打印/下载、正常关闭及崩溃重开缺口仍保留，不因推进 P2 关闭。

环境：Windows、Python 3.13.7（显式使用 `artifacts/modernization/p1-validation-venv/Scripts/python.exe -X utf8`）、Node 24。所有测试使用 E 盘隔离数据库/目录和 loopback Mock；不重启、不修改 `127.0.0.1:8000` 的现有服务、数据库或凭据。不自动合并、发布或现场安装。

## 实现范围

- P2-01/02：追加持久任务表、旧入口兼容、分页/本人权限/管理员查询、关联新任务重试；前端识别 interrupted 终态并保留任务 ID。OpenAPI 与首批任务 TS 类型同步生成。
- P2-03/04：可序列化快照、源版本/数据水位、独立 SmdRender（并发 1）、三格式渲染、环境白名单、超时/取消清理。冻结依赖与安装必需文件同步更新；worker 无数据库/通信/配置导入，但不是 OS 文件沙箱。
- P2-05：启动遗留任务中断且不自动重跑，归档前来源复核、产物摘要与下载核验；磁盘不足/进程失败保留可查询原因。源日志仍由原网关执行且不自动重扫。重试重新采集当前来源，旧快照不覆盖。
- P2-06：事件循环/持久化/队列/worker/通信统计/磁盘指标；缺少观测保持未知。未更改 HostComm 报文或设备控制重试策略。
