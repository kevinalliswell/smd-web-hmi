操作规程
▶️ 启动一次试验
1确认设备就绪：控温仪、MFC、天平、安全继电器均显示「正常/允许」
2进入「当前试验」页，填写样品编号和试验备注
3确认启动前检查全部通过（8项绿色）
4点击「启动试验」，系统自动分配 test_id 并保存参数快照
5切换至「实时总览」监控状态机推进，关注安全状态栏
⏹ 正常停止试验
1确认试验已满足结束判据（滴落重量达标且 ΔP 稳定）
2在「当前试验」点击「停止试验」，阅读二次确认提示
3确认后控制板进入 Purge → Cool 流程，CO 自动关闭
4观察状态机进入 Cool，待「实时总览」显示设备冷却完成
5进入「报告生成」导出本次试验报告
🚨 报警处理流程
1顶部橙色/红色横幅显示报警内容，查看等级和报警码
2进入「报警事件」查看完整报警信息和建议处置
3排查现场后，点击「确认」记录确认人和时间
4若为 L3 故障，等故障消除后在「当前试验」点击故障复位
5注：消音不清除报警；报警确认不等于故障复位
📊 导出历史数据
1进入「数据分析 → 高级查询」设置筛选条件
2点击「查询」确认结果集后，点击「导出 Excel/CSV」
3如需图文报告，进入「报告生成」选择模板和试验编号
4导出文件默认保存至系统设置中配置的报表路径
⚙️ 修改工艺参数
1需要管理员权限；试验运行中关键参数被锁定
2进入「参数配置」，选择对应标签页
3修改参数后点击保存，系统记录修改前后值和操作者
4下发控制板后必须确认回读结果与设定值一致
🔧 通信中断处理
1顶部状态栏显示「STM32 通信中断」红色徽标
2STM32 本地安全流程不受影响，请先检查现场设备安全
3进入「设备诊断」查看心跳和 HostComm 状态
4检查以太网连接和 STM32 工控机 IP 配置
5后端自动重连；恢复后数据从设备日志补齐

🔒 CO 相关操作安全规定 ▶
所有 CO 相关操作必须严格遵守以下规定：
1. CO 工艺请求只能由 STM32 状态机在安全条件满足时自动发起，上位机不提供手动强制打开 CO 阀的功能。
2. 若安全继电器不允许，CO 相关操作按钮将自动禁用，并显示禁用原因。
3. 涉及 CO 流量变更的操作，必须通过参数下发（管理员权限），由控制板状态机执行，不可直接修改 MFC。
4. 排风系统必须在 CO 工艺开始前处于运行状态，否则无法通过 Precheck。
5. 发生 CO 浓度报警时，操作员必须现场确认排风和气体供应状态，不得仅凭上位机确认报警后继续操作。
⚠️ 上位机断线时的操作规程 ▶
上位机（Web 浏览器或后端服务）断线时：
1. STM32 本地自动安全流程不受影响，设备将继续按状态机运行。
2. 操作员应立即前往炉旁，通过控制板本地显示或指示灯确认设备安全状态。
3. 不得依赖 Web 上位机完成安全动作或紧急停止；安全停止应通过硬件急停按钮实现。
4. 后端服务重启后会自动重连，并从控制板日志补齐断线期间数据。
5. 若长时间无法恢复上位机连接，应记录纸质操作记录，并在恢复后在备注中补录。

角色权限说明：
• 观察员：只读查看实时状态、历史试验和报表，不可执行任何操作命令。
• 操作员：可启动/停止/暂停试验、确认报警、天平去皮、导出日志。
• 管理员：可修改参数配置、管理用户、导入设备 profile。
• 维护员：可访问设备诊断、导出通信日志，不可绕过安全回路。

账号安全要求：
• 不得共用账号；每个操作员使用独立账号登录。
• 离开操作台时应退出登录。
• 账号密码修改需通知管理员记录。
💾 数据备份与恢复规程 ▶
1. 系统默认每日凌晨 6:00 自动备份数据库至「系统设置 → 备份路径」。
2. 重要试验结束后应手动触发一次备份。
3. 原始曲线数据和事件日志不允许在界面直接删除；报表文件可重新生成。
4. 从备份恢复必须在试验停止状态下进行，恢复操作由管理员执行，并记录恢复原因。
5. 数据保存年限遵守实验室数据管理要求（待制定后更新）。
📞 技术支持与联系方式 ▶
上位机软件问题： 联系上位机开发团队

⏸ 确认暂停 / 保持？
将向控制板发送 pause_hold 请求。STM32将切换到Hold状态，保持当前温度和气体制度，等待手动继续。
⚖️ 确认天平去皮？
将向控制板发送 tare_balance 请求，天平当前读数 3.84 g 将被清零。
